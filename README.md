# Parshwanath Yatra Route Planner

Static site (no build step): Leaflet map, OSRM road routing, tirth database and dharamshala list.

- `index.html` app
- `tirths.js` 108 Parshwanath + major tirths data
- `stays.js` dharamshalas near each route stop (from Google Maps listings; confirm by phone)

Deploy on Vercel as a static site: framework preset "Other", no build command, output directory `.`
